# Minecraft Bot 工程约定

本目录拥有 Minecraft 动作、任务、安全阈值、世界记忆与 Agent 会话。遵守根 AGENTS；先读 [MCBOT](../../docs/MCBOT.md) 和 [API](../../docs/API.md) 的本机契约。命令从仓库根执行。

## 当前范围与长期安全约束

- 当前工具集合由 `src/autonomy/tools.ts` 定义，共 13 个，任务由 `AUTONOMY_TASKS` 白名单限制。不自行新增第 14 个工具、挂载 goal-round-driver 或向模型开放 plugin-manager；只有当前任务明确批准范围调整并同步策略、契约和测试后才能扩展。
- 自主动作只接受主人显式启动或管理员对话中的明确指令。普通聊天、意图解析和路点建议不获得动作工具；提示词的 status/inventory/task_status 是上下文段，不等于可执行工具。
- 生产自主工具经 DSH 插件与私有 Unix socket 调用。没有 `DSH_AGENT_SOCKET` 时自主会话不可用；配置后 `/autonomy/mcp` 返回 404。自主会话与管理员对话没有 OpenCode 回退，不能向应用、浏览器或公网暴露 MCP。
- 每次运行使用独立 run_id、短期凭据与子进程；急停先撤销工具调用权，再取消模型、运动和任务，收口旧会话/容器/子进程后才允许新运行。清理失败须重试，迟到结果不得恢复已撤销的动作。
- 时间、工具预算、连续失败、断线、手动操作和急停均 fail-closed；每轮模型等待受总决策超时与会话剩余时间约束。事件触发重决策保留去重与次数上限，不引入周期空转。
- 不做 PvP、建筑、踢人、封禁、OP 或备份触发。寻路与传送遵循既有安全边界，不因模型建议绕过血量、饥饿、威胁或操作占用校验。

## 工具、任务与记忆

- `observe` 只读半径内白名单环境；`inspect_chest` 仅在无 active/queue/pending 时短距寻路只读容器，不取物、不传送、不破块。`eat`/`equip` 只在空闲时对背包物品生效。
- 任务/移动/目标关联具体执行实例与实际操作，不能凭任务同名或重复事件推进。暂停/取消先撤销换步权，再停止所属操作并收口容器；目标状态与步骤同事务写入。
- 多步目标的已完成步骤保留，重启后暂停、任务转待恢复；只能由获准入口确认恢复，不能自动重跑完成步骤或从 Workbench 恢复旧控制面板。
- 世界记忆与聊天记忆分开；分类只有 place、resource、food、danger、route、note。按维度隔离，权限 0600；断线不能回退读取主世界。具体文件命名以世界记忆模块为准。
- 提示词只带当前维度、分类计数和最近 8 个键；正文按工具受控读取。资源点只记录实际观察并复核的方块，到场复核失效后回退扫描。不开放跨维度移动。
- 记忆工具计入既有预算且不启动任务。不得在日志、审计或应用 DB 写 prompt、Token、完整容器内容、世界记忆正文或聊天正文。

## HTTP 与运行时

- HTTP 契约版本以 `src/contract.ts` 和 `deploy/tool-versions.json` 为准，当前仅 v2；只监听 loopback，不进入 Cloudflare 或防火墙对外规则。读/控制 Token 分离，`/say` 由控制 Token 认证并拒绝 ASCII `/` 与 C0。
- 管理员对话允许 `/`，不把该正文直接送入游戏。时间线仅内存，最多 80 步，标题≤120 字；只暴露文本、工具名/成败、目标/待办动作与短标题，急停清空。
- 保留任务白名单、天然林/挖矿资源复用、安全反射和内存事件 ring。环境键与阈值从配置和模板读取，不在指令文件维护一份默认值。
- 部署/回滚读取 [部署约定](../../deploy/AGENTS.md) 与 [DEPLOY](../../docs/DEPLOY.md)，等 Bot 空闲后切换，不能重启 Minecraft 代替 Bot 故障处理。

## 验证

- `npm run check:mcbot` 执行类型检查与离线单元/Agent 夹具；覆盖率使用 `npm run test:coverage -w @antifieldcomplexx/mcbot`。相关脚本测试随根 `npm test` 执行。
- 覆盖迟到结果、重复事件、断线、超时、预算耗尽、取消收尾、急停后再启动、旧凭据重放和跨维度记忆隔离。使用假 Bot/DSH/socket，不访问真实 Minecraft 或模型。
- 工具/任务/环境声明同步 MCBOT 和 API，执行 `npm run check:docs`。实机路径和动作验收必须单独记录，未触发的场景保留为缺口。
