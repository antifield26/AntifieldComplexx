# 客户端工程约定

本目录负责 React 界面与 Tauri Windows/Android 容器。遵守根 AGENTS；修改交互先读 [UI-SPEC](../../docs/UI-SPEC.md)，接口先读 [API](../../docs/API.md)，原生构建与签名先读 [DEPLOY](../../docs/DEPLOY.md)。下列命令从仓库根执行。

## 模块与能力边界

- 源码在 `src/`；构建产物写入 `apps/workbench/web/dist`。服务端不参与前端编译，不提交生成产物。原生源码、权限与配置纳入版本控制，不依赖生成目录的手工改动。
- 保持石墨黑与暖橙品牌、现有组件与响应式布局。Windows 自绘标题栏，Android 固定底部四项导航；滚动/回弹只作用于内容区。尊重减少动画设置和触控区域要求。
- 受保护的非首页路由懒加载，沿用加载提示与错误边界。登录入口及静态预加载 JS 压缩前合计不超过 500 kB。不提供 PWA 安装和离线壳；缓存清理使用兼容标识。
- Workbench 的 Minecraft 页只展示状态、管理员对话与事件，保留在线模式、停止和急停。不要恢复任务/目标/移动/游戏发言/历史代理入口。

## 认证与原生边界

- 设备密钥只由原生受控接口管理；IPC 权限只给对应本地窗口。远端 AI 使用隔离窗口或 Activity/WebView，不获得命令、文件或设备签名能力。
- 原生侧校验固定 API/AI 来源与 SSO 路径；换票保持 User-Agent 一致性。校验 HTTP 和 WebSocket 生命周期，重复打开、失败恢复和登出均需释放旧连接。
- 文件与附件预览、下载、上传使用受控认证传输；大文件流式落盘，不把会话令牌放入下载 URL。原生保存/打开使用系统选择器，不接受远端页面提供的任意本机路径。
- 持久化浏览状态按服务来源与账号隔离，只保存普通页面、视图和排序；筛选与滚动保留在本次运行内。密码、验证码、正文、分享凭据、SSO 链接和待提交指令不得持久化。退出/吊销清理账号相关状态。
- 只读请求有限重试、合并并离页取消；写操作一次明确提交。刷新失败保留旧数据和更新时间，区分网络、服务、会话过期与设备吊销。
- Android 返回依次关闭顶层弹窗、返回上级、回首页，再使用系统后台行为；未保存编辑离开需确认，提交中防止重复操作。

## 验证

- React 改动运行相关 Vitest，必要时 `npm run test:web`。版本/配置改动运行 `npm run check:client`；生产构建使用 `npm run build`。
- Rust 逻辑改动运行 `cargo test --locked --offline --manifest-path apps/client/src-tauri/Cargo.toml`；依赖尚未缓存时说明环境缺口，按任务授权补齐后验证。
- Windows 使用 `npm run build:client:windows`，Android 使用 `npm run build:client:android` 的受控构建路径；固定工具链和既有签名身份，遵循 DEPLOY，不私自重签生产包。
- 真机验收区分平台与包哈希，覆盖升级、登录恢复、文件、AI 返回和原生外观；Bot 动作的 UI 测试使用夹具，不对生产触发动作。
